# 手机上怎么用（iOS / 鸿蒙 / 安卓）

仰山课表**不需要装应用**也能在手机上用。iPhone 和鸿蒙手机没有对应的壳，
走的是「网页 + 加到主屏幕 + 日历订阅」这条路 —— 功能和壳里几乎一样，
唯一少的是「每小时自动抓一次」，而那个缺口由 **日历订阅**补上（手机日历会自己去轮询）。

安卓另有真正的壳（`shells/android/`），能自动登录、自动刷新，见那边的 README。

---

## 一、把网页加到主屏幕

加到主屏幕之后它就像个 App：有自己的图标、全屏打开、不显示浏览器地址栏。

### iPhone / iPad（必须用 Safari）

1. 用 **Safari** 打开仰山课表的网址。⚠️ 必须用 Safari —— Chrome、Edge、微信内置浏览器
   都提供不了「添加到主屏幕」，它们只能加普通书签。
2. 点底部中间的**分享**按钮（方框 + 向上箭头）。
3. 往下滑，选**添加到主屏幕**。
4. 名字会自动填成「仰山课表」，点**添加**。

之后从主屏幕图标进去，就是个独立窗口。数据存在这台设备上，断网也能看课表。

### 鸿蒙 / 华为手机

1. 用**华为浏览器**打开网址。
2. 右下角**菜单**（三条杠）→ **添加到桌面**。
3. 确认。

部分机型会提示「添加为服务卡片」或「添加书签」—— 选**添加到桌面**那一项，
出来的是能直接点开的图标；只加了书签的话，得从浏览器书签里进，体验差一截。

### 安卓手机（不想装壳的话）

Chrome → 右上角 `⋮` → **添加到主屏幕**。

## 二、把课表导进去

三种入口都在「我的 → 导入课表」。手机上最顺手的是前两种。

### 路一：上传教务导出的文件（最推荐）

教务系统里导出课表时能选 **Excel(.xlsx)** 或 **Word(.docx)**，两个都支持，随便哪个。

> **导出的文件比接口还全。** 实测同一门课（程序设计基础(C语言)B）接口只给到第 13 周、
> 且教室没变，导出的文件里还有第 14–17 周、教室换成了 MLC-104。
> 所以这不是「退而求其次」的办法，它拿到的课表可能比自动抓取更完整。

手机上的操作：把文件传给自己（微信「文件传输助手」/ QQ / 邮件都行），
点开文件 → **用其他应用打开** → **存储到「文件」**（iOS）或存到下载目录（鸿蒙/安卓）。
然后回到仰山课表，点「上传课表文件」，选中它。

表格里没有「学期从哪天开始」，所以导入面板会问一句**「今天是第几周」**，
再顺手把「第 1 周的星期一」算给你看。这两个数字对着教务系统首页的「第 N 周」填一下就行。

### 路二：截图（OCR 自动识别，识别完还能改）

点「课表截图」，选一张课表截图，等它自己认字。认完会弹出一个**可编辑的网格**，
把认错的字改掉、认出来的空行补上，再保存。

不用自己用系统识图：从 2026 年起这个流程是**全自动**的（内置中文 OCR 模型，纯本地跑，
图片不会离开你的手机）。识别率对手机截图大约 85%，所以「认完给你改」才是正路，
不要指望它一次全对。

如果自动识别出的结果实在太乱（比如截的是深色主题、或者图片被压过），
面板里还有两条退路：
- **系统识字后粘贴**：iOS 用「照片 → 长按 → 拷贝文字」，鸿蒙/安卓用系统识屏，
  微信里长按图片也能「提取文字」。复制到的文字粘进来，它认表格结构认得很准。
- **对着截图照抄进格子**：最后那个「手动填」入口，14 节 × 7 天的网格。

### 路三：抓取工具（书签小工具）

在电脑上最省事，在手机上比较别扭但仍可用。

先把「我的 → 抓取工具」里的那段 `javascript:` 代码存成书签：

- **iOS Safari**：随便存一个页面为书签 → 编辑书签 → 把地址整段换成那段 `javascript:` 代码。
  用的时候在地址栏输入书签的名字，从下拉建议里点它。
  ⚠️ 直接从书签列表里点**不会执行**，这是 iOS Safari 的规矩。
- **鸿蒙 / 安卓浏览器**：新建书签 → 地址填那段代码。用的时候在教务系统页面上点这个书签。

然后：**先在同一个浏览器里登录教务系统**，打开课表页，再点这个书签。
它会浮出一个小面板，抓完把结果复制到剪贴板（失败了会给你一个全选的文本框兜底），
再回到仰山课表「粘贴导入」粘进去。

> 为什么要绕这一圈？因为学校教务系统不给跨站访问（没有 `Access-Control-Allow-Origin`，
> 会话 cookie 还是 `SameSite=Lax`）。任何云端的网页都拿不到你的课表 —— 这不是没写，
> 是浏览器层面的硬墙。书签运行在学校自己的页面上，所以没有这道墙。

## 三、让提醒真正可靠：日历订阅

**应用内提醒不可靠，也别指望它。** 手机浏览器不让网页在后台定时唤醒，
页面一关提醒就停。真正的提醒应该交给系统日历 —— 那是操作系统自己管的事。

### 导出

「我的 → 导出 → 导出日历 .ics」，会下载一个 `.ics` 文件。

### 要订阅，先得有个网址

日历订阅（而不是一次性导入）需要一个**能公网访问的 .ics 地址**。
把导出的文件传到任意一个静态托管上就行，几个常见选择：

| 放哪 | 出来的地址长这样 |
| --- | --- |
| GitHub Pages（`<用户名>.github.io/<仓库>/xxx.ics`） | `https://你的用户名.github.io/kb/2026-2027-1.ics` |
| GitHub Gist（建完点 Raw） | `https://gist.githubusercontent.com/.../raw/xxx.ics` |
| Cloudflare Pages / Vercel / 对象存储 | 各自给的公开网址 |

⚠️ 课表本身不含特别敏感的信息，但它毕竟是你每天在哪儿的行程。
放公网时**别用能猜到的文件名**（例如别用学号命名），图省事的话可以加一截随机串。

### 订阅（iOS）

**设置 → App → 日历 → 账户 → 添加账户 → 其他 → 添加已订阅的日历**，
「服务器」一栏直接填那个 `https://...ics` 网址（填 `webcal://` 开头也行，iOS 会自动换）。
保存后可以在「账户 → 已订阅的日历」里把「移除提醒」关掉、把「刷新」设成每小时。

### 订阅（鸿蒙 / 安卓）

- **华为日历**：部分版本没有通用的网址订阅入口。先试 **日历 → 左上角菜单 → 订阅管理**；
  没有的话用下面两条。
- **导入一次**：在文件管理器里点开 `.ics` → 用「日历」打开。适合更新不频繁的情况，
  缺点是下次教务改课不会自动跟上。
- **换个日历 App**：**Outlook**、**Google 日历**（网页版「其他日历 → 通过网址添加」）、
  **1Calendar** 这类都支持按网址订阅。订阅一次就一劳永逸。

### 关于「自动更新频率」

- 装了**壳**（Windows / 安卓）：壳每小时去教务抓一次，课表变了会重新生成。
- **只加了主屏幕图标**（iOS / 鸿蒙）：网页自己不会在后台跑。
  想要「改了课自动跟上」，就得靠日历订阅 —— iOS 会按你设的刷新间隔去拉那个 `.ics`，
  这是唯一真正可靠的全自动路径。
- 想手动跟一次：打开主屏幕上的图标 → 「我的 → 抓取 / 导入」重来一遍。
  重新导入不会产生重复事件：每节课的 ID 里不含教师和地点，
  所以换教室、换老师都是**原地更新**。

## 四、常见问题

**「添加到主屏幕」找不到这个选项？**
iOS 上一定是没用 Safari。Chrome / Edge / 微信 / QQ 内置浏览器都没有这个功能。

**导入之后提醒不响？**
网页版的提醒只在页面开着的时候有效。要可靠的提醒，走上面第三节的日历订阅。

**课表里的星期不对 / 少了几门课？**
先看「今天是第几周」填对没有 —— 填错一周，整学期的日期都会平移一周。
用「我的 → 编辑课表」改；改的时候学期周历会沿用原来的，不会再次平移。
少课的话多半是那门课在教务系统里属于「未排课」，它在课表页下方单独列着（点那行虚线框）。

**换了手机怎么办？**
「我的 → 导出备份」存一份 JSON，在新手机上「恢复备份」。或者重新导入一次课表。

**会不会把我的账号密码传到你们服务器？**
不会。仰山课表没有服务器，账号密码只在装了壳的设备上使用，
而且只用于登录学校自己的页面；网页版根本收不到密码（它连教务系统都连不上）。
