推送频道

这套推送是怎么工作的（以及它为什么安全）

公告的真正内容只存在仓库里的 data/announcements.json —— 那才是全班看到的同一份东西。推送（ntfy.sh）只当门铃：响一声，应用就回来重新读文件。 所以就算频道名被外人知道、有人往频道里发假消息，也只能让同学多刷一次公告，注入不了任何文字。
反过来说，推送失败也不会丢公告：应用每次打开、每 15 分钟、每次切回标签页都会自己拉一次。

本页是纯静态页面，没有后端。所有写入都直接走 GitHub API，提交记录里能看到是谁改的。
